## 4. Главные находки и данные этой сессии

**Перенос ускорения между поколениями (DECISIONS 51).** Приём драфтера (токены за раунд) — свойство
пары: на 9B MTP Q4_K_M Ada и Ampere совпадают на всех конфигурациях (dflash:7 3,79/3,80; mtp:3 3,15/3,15).
Цена раунда в шагах plain — свойство поколения: Ampere дороже Ada на ×1,02 (dflash:3) … ×1,09 (dflash:7)
… ×1,21 (dflash:11), mtp:2…5 ×1,06…×1,11. Отсюда #146.

**Ampere (RTX 3060) без флагов:** 9B GGUF Q4_K_M — DFlash подключается сам, ×1,59 на смеси (план
переносил Ada ×2,31). С парой Ampere: 9B MTP Q4_K_M ×1,64 = 0,81 своего профиля; Q6_K ×1,89 = 0,88.
Отношение «смесь / профиль» ≈ 0,81–0,88 и на Ada — это состав задач (DECISIONS 50, вопрос владельцу).

**Volta (Quadro GV100) — важная открытая находка.** 9B GGUF Q4_K_M без флагов: план dflash:7 (×2,31 по
Ada), старт подключил DFlash, но **смесь 72,3 против 70,9 ток/с = ×1,02** — спекуляция почти ничего не
даёт. Нужно: spec-tune 9B на GV100 (пара Volta) — тогда #146 сам поправит оценку; и, возможно, выбор
должен давать plain/MTP на Volta. Проверить связь с PR разработчика #36/#70 (verify-срезы Volta).

**Префилл (см. #147):** модель `eta·peak/(2·params)` без FLOP внимания по контексту. Замеры 4090, 22K:
Gemma 12B 6144 ток/с, Gemma 26B-A4B 13196, Qwen 9B 11828.

**Лимит хаба (#145, в master):** все стенды выходят в интернет с одного IP; анонимный лимит API HF —
500 запросов за 5 минут. Массовые прогоны планов (сравнения 28 планов × 2 бинарника) его упирают.
Если у стендов будет HF_TOKEN — лимит выше.

- Имена без IP резолвятся неверно — использовать IP или `<name>.local`.
- Протокол GPU: общий файл-замок `/root/GPU_BUSY` (lab.sh: `lock <тег>` / `unlock`), очередь
  разработчика `/root/queue` (runner.sh). Мои файлы — только в `/root/claude`.
- Сборка: `/root/claude/run_cb.sh ARCH targets...` с `BR=<ветка>`; каталог сборки ~48 ГБ — удалять
  сборки смерженных веток (на 2080 Ti диск однажды заполнился).
- **GV100:** CUDA 13 не собирает Volta → `/usr/local/cuda-12.8` + `g++-14`; в
  `/usr/local/cuda-12.8/targets/x86_64-linux/include/crt/math_functions.h` перенесены 6 объявлений с
  `noexcept` из 12.9 (glibc 2.43; оригинал — `.orig`). **У хоста неисправное ядро CPU 8/9
  (i7-14700KF)**: компиляторы падают только на нём — тяжёлое запускать под `taskset -c 0-7,10-27`.
  Владельцу сообщено (BIOS/микрокод или отключить ядро). Вывод «CUDA 12.9 cicc падает на sm_70» был
  ошибочным — это было то же ядро.
- 4070 Ti: нет venv с numpy — fetch_test запускать на 2080 Ti (`venv-torch`).

## 7. Уроки (чтобы не наступать снова)

- Ждуны вида `while pgrep -f "имя"` совпадают сами с собой — ждать маркер в файле (`until grep -q DONE файл`).
- Python-однострочники с f-строками в ssh ломаются экранированием — класть проверку в файл
  (`choice/handoff/scripts/plan_spec_row.py`, `gp_cmp.py`, `roundcost.py`, `gen_ratios.py`).
- Не убивать процессы `pkill -f` прямо в строке ssh (убивает сессию) — только по PID или скриптом.
- Различия планов между двумя бинарниками сначала повторить: сбой чтения с хаба (429) давал ложные
  различия; после #145 их быть не должно.
- Сравнивать цену раунда между картами только на одних и тех же весах (разные кванты исказили
  первую оценку Ampere: 1,165 вместо 1,09).
