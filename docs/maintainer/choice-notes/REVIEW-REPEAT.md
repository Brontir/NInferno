## Прозрачность и чистота (полировка после критичного)

- Мёртвое: `ServedChoice::target_context` (дубль `choice.context`), `QuantPlan::chosen` (= `pick->index`); экспортируемые `served_fit_fallback`/`served_head_fallback`/`served_shallower`/`shallower_*` — только тесты (в анонимное пространство, тесты через `fit_fallbacks`); тексты `recWhy*` не читаются (`recWhyRule` описывает удалённое правило «10 % от быстрейшего 4-бит»); `drafter_bytes` из п.1 не читается.
- Имена/комментарии: `QuantRow::largest` ставится на выбранный по ценности ряд (настоящий крупнейший — `largest_index`) → `picked`; подсказка «★ — самый крупный, что влезает» неверна при выборе по ценности; ссылки на `choice/SPECULATION.md` в коде — файла нет в репо; `defaults_why` присваивается внутри условия `else if`.
- Причина решения выводится заново в `explain` (8 ветвей, порядок задаёт приоритет) вместо записи в момент решения — три текста расходятся (why, why_not, перевод страницы).
- Числа без имени: 1024 вместо `kDefaultChunk`, тексты «3»/«3,5 бита» при наличии констант, `5*… >= 4*…` правила пула, глубина оценки `max(512, ctx/4)` в трёх местах.
- Украинский: нет 98 ключей (основа выбора и спекуляции падает на английский) → тест паритета EN/RU/UK.
- Остатки удалённого: комментарий «the Session runs … adaptive depths» в `tests/test_spec.cpp`; `docs/serving.md` «модель без профиля декодирует без спекуляции» (неверно: встроенный драфтер по умолчанию).
