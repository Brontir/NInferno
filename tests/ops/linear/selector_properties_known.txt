# Violations of the selector properties that exist today (test_selector_properties.cpp), one per
# line: <property> <subject> [@<route set> ...] [%<board or group> ...]. No @set: every set; no
# %board: every board. A group is "group <name> <board>..." (lines of one name add up); known-pci
# (a PCI id the reference table knows) and unknown-pci are built in. Each entry is a known gap of
# docs/maintainer/deterministic-decisions.md; remove it in the change that closes it. A violation
# on a board no entry covers fails, and so does an entry a board it names (directly, through a
# group or a class) no longer shows.

# No environment variable moves a choice: the route-table, tuner and verify knobs became options
# (#51), and the suite sets every NINFERNO_* variable (removed ones too) and sees no change.

# The cost model reads the PCI-ID reference facts (#38); a board the table does not know takes the
# driver's clocks (labelled extrapolated), so zero (MIG, WSL) or skewed clocks still move the speed
# profile there: on the boards with an unknown PCI id (b300, gb10-spark, unknown-sm120-48sm and
# every synthetic board), and on none of the known ones. The prefill and invariant profiles do not
# move.
P2-clock speed %unknown-pci

# The prefill profile takes ggml's matrix kernel for the ggml formats under AllowA8 from 17 tokens

# splits K by the call's tiles), so a token's bytes follow its chunk's width (gap: "MMQ prefill
# bytes depend on where a chunk is cut").
