# Shortlist rankings named by the drafter registry

A drafter entry in `src/spec/data/drafter_registry.json` may carry `"proposal_rows": N` and
`"ranking": "<file>"`: `ninferno-convert --fetch` (and `--attach-drafters`) then converts that drafter
with its output head restricted to the N most frequent tokens of the ranking. The converter finds
the file by name here: in the working directory's tree, then among the rankings installed beside the
binary (`share/ninferno/rankings`), then in the tree the binary was built from. A converted drafter records the ranking in its provenance as
`<file> sha256:<digest>`, so the drafter's bytes do not depend on where the file lay.

A ranking is little-endian int64 counts over the model's whole vocabulary (one row of
`vocab_size` entries); `shortlist_ids` in `src/convert/checks.cpp` turns it into the head's rows.

## gemma4_ranking2.i64

Token counts of text the way Gemma 4 writes it, rendered through its chat template, in two passes:

1. GSM8K Platinum answers generated by Gemma 4 itself (NInferno runs, seed 1234), GSM8K train
   questions and answers as chat turns, and the first 20 % of WikiText-103 train.
2. Added on top: 20,000 UltraChat 200k assistant turns (general and code chat), 20,000
   CodeFeedback-Filtered-Instruction answers (code in many languages) and 20,000 Aya dataset
   answers (multilingual), each as a user/assistant chat turn.

Pass 2 exists because pass 1 alone dropped the 64k-row shortlist's acceptance on code from 0.76
to 0.52. Share of held-out tokens inside the top 64k rows after pass 2: code 99.3 %, chat 98.4 %,
multilingual 91 %. The registry uses 98,304 rows for the Gemma 4 26B-A4B and 31B assistants
(`google/gemma-4-26B-A4B-it-assistant`, `google/gemma-4-31B-it-assistant`), the size chosen
when their profiles were measured on 2026-09-23.

The file is the reference: pass 1 counted generations from one local run, so a rebuild from the
datasets alone would differ in low-frequency ranks. Treat a new ranking as a new file name (and a
new registry entry), never as a replacement of this one.
